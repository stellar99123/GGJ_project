## 1. 游戏概述

| 项目 | 内容 |
|------|------|
| **名称** | 《Bound to Grow》（中文名《汐缠》） |
| **类型** | 像素风 · 场景互动解谜（point-and-click 叙事驱动） |
| **题材** | 深海人鱼 × 海洋塑料污染隐喻 |
| **主角** | 小人鱼「汐」（约 15 岁，21 世纪） |
| **核心机制** | WASD 移动 + 键盘交互的场景互动解谜（探索 / 拾取 / 组合 / 使用 / 推理 / 抉择） |
| **灵感来源** | 《独自在家》（单人独处 + 场景机关互动） |
| **目标受众** | 叙事解谜爱好者、环保议题关注者、独立 / 像素美术玩家 |

**一句话立意**：以美人鱼「缠线成年、长大致死」的宿命悲剧，隐喻海洋塑料污染危机——*「我们以为的长大，是被垃圾困住的一生。」*

### 世界观与时间线

- **汐渊海**：海平面千米之下与世隔绝的蔚蓝海域，栖息着古老的**澜汐人鱼族**。
- **汐纹线**：传说中由深海星光凝结、滋养尾鳍的成年礼圣物，天然柔韧的海底发光纤维。幼崽尾鳍澄澈，成年时缠绕专属汐纹线，丝线越密代表成长越圆满。
- **时间线逻辑**：
  - 人鱼寿命 200–300 年。
  - **长老约 220 岁**，在 19 世纪末（约 120 年前）完成成年礼，当时海洋尚未被工业污染，他缠的是**真正的深海星光线**。
  - **汐约 15 岁**，身处 21 世纪，天然星光线已彻底绝迹，被海面坠落的塑料鱼线、化纤废网取代。
- **悲剧真相**：族群无法辨识人造材料，把硬质、透明或彩色的塑料线误认为新一代「汐纹线」。长老用百年前的传统经验要求后辈，无人意识到「越长大、越窒息」的诅咒，本质是坚韧不可降解的塑料线随身体发育不断嵌入皮肉、绞断血脉的物理伤害。

## 2. 核心玩法

### 基础规则

玩家扮演汐，在海底场景中通过移动与按键互动推进叙事、解开谜题。无战斗、无数值养成，核心是**探索环境、收集线索、解锁剧情**。

- **隐藏物品机制**：关键饰线不直接暴露，而是藏在海藻、贝壳等障碍物后；玩家靠近并按空格「拨开 / 打开」，才会显露可拾取的饰线。
- **碰撞体机制**：海藻、贝壳等障碍物具有碰撞体，玩家无法直接穿过，必须绕行或先按空格处理。

### 操作方式（键位）

| 按键 | 功能 |
|------|------|
| **W / A / S / D** | 控制汐移动 |
| **E** | 与人物对话 / 与物品交互 |
| **F** | 拾取道具入物品栏 |
| **空格（Space）** | 拨开海藻 / 打开贝壳，显露隐藏的饰线 |
| **1 / 2 / 3 / 4 / 5** | 选中物品栏对应格（选中高亮），供「使用 / 组合」后续章节操作 |

> 注：`Tab` 背包、「组合 / 使用」等属于第二～四章的扩展设计，当前原型未实现（原型只有移动 / 对话 / 拾取 / 搜索 / 选格）。

### 互动循环（7 种核心操作）

| 操作 | 键位 | 说明 |
|------|------|------|
| ① 探索观察 | E | 靠近可交互物件，按 E 播放描述 / 线索文本 |
| ② 搜索 | 空格 | 靠近海藻 / 贝壳，按空格拨开 / 打开，显露隐藏道具 |
| ③ 拾取 | F | 靠近高亮道具，按 F 收入背包 |
| ④ 组合 | Tab | 背包中选中道具 A + 道具 B，特定组合合成新道具 |
| ⑤ 使用 | Tab + E | 背包选中道具 → 靠近场景目标按 E，触发效果 |
| ⑥ 推理 | 自动 | 集齐指定线索 → 触发结论剧情 |
| ⑦ 抉择 | 弹窗选择 | 关键节点弹出选项 → 锁定结局分支 |

### 胜负 / 结局判定

- **无 Game Over**：整个游戏没有失败状态，最坏情况只是暂时卡在当前场景。
- **双结局**（由第四章抉择 + 隐藏线索共同决定，见 §5）：
  - **宿命结局（悲剧）**：顺从规则、补齐丝线 → 尾鳍锁死，沉入海底。
  - **救赎结局（隐藏）**：集满 3 件隐藏线索 + 完成挣脱三步操作 → 拆解塑料枷锁。

## 3. 解谜规则与进度判定

### 操作规则

统一框架：**[操作类型] + [目标物件/道具] → [判定结果]**

| 操作 | 键位 | 规则 | 判定结果 |
|------|------|------|---------|
| 探索观察 | E | 靠近可交互物件按 E | 播放描述 / 线索文本（无消耗） |
| 搜索 | 空格 | 靠近海藻 / 贝壳按空格 | 拨开 / 打开 → 显露隐藏道具 |
| 拾取 | F | 靠近高亮道具按 F | 道具入背包 |
| 组合 | Tab | 背包中选中道具 A + 道具 B | 特定组合 → 合成；不匹配 → 提示「无法组合」 |
| 使用 | Tab + E | 背包选中道具 → 靠近场景目标按 E | 匹配 → 触发效果；不匹配 → 提示「无法使用」 |
| 推理 | 自动 | 集齐指定线索 | 触发结论剧情 |
| 抉择 | 弹窗选择 | 关键节点弹出选项 | 锁定结局分支 |

### 卡关与错误处理

| 场景 | 响应方式 | 惩罚 |
|------|---------|------|
| **操作错误** | 弹出符合剧情的软性提示语（如「这条线太紧了，需要更锋利的工具」） | 无 |
| **卡关** | 点击「提示按钮」→ 高亮目标 + 文字线索 | 消耗 1 次提示 |
| **提示用尽** | 只能靠剧情提示语与自主探索 | 无（不会卡死） |

**提示次数**：每章 2 次，章内消耗、不跨章累计，UI 以「星光」图标显示剩余次数。

### 难度曲线

| 阶段 | 复杂度 | 递进方式 |
|------|--------|---------|
| 前期（第一、二章） | 拾取 → 组合 + 顺序 | 单一操作 → 组合 |
| 中期（第三章） | 三线索联动推理 | 多场景串联 |
| 后期（第四、五章） | 抉择 + 3 步连锁 | 复合连锁 + 结局抉择 |

成长曲线平滑递增，无跳跃式膨胀。

## 4. 系统设计（内容池）

### 分层体系

| 层级 | 定位 | 功能 |
|------|------|------|
| **主线道具** | 必需 | 推动进度、构成通关门槛 |
| **主线线索** | 必需 | 串联触发「识破真相」 |
| **隐藏线索** | 稀有 · 可错过 | 集满 3 件 → 解锁救赎结局的「觉悟」 |
| **剧情物件** | 氛围 / 叙事 | 可观察或可作用，铺陈世界观 |
| **NPC / 角色** | 剧情驱动 | 对话与催促剧情 |

### 设计框架

每个道具 / 物件统一由三要素组成：

> **[获取方式] + [用途/作用] + [剧情关联]**

### 内容范例

**主线道具**
- `虹彩饰线 ×3`｜珊瑚区拾取｜集齐触发初缠仪式｜第一章通关门槛
- `礁石碎片`｜第四章点击【锋利礁石】｜磨断外层丝线（拆解工具）｜挣脱分支关键

**主线线索 ×3（第三章，必经）**
- `受创人鱼的尾鳍`｜观察（莉娅）｜丝线勒进肉、流血｜伤害铁证
- `包装袋残片`｜废墟翻找｜印「聚乙烯 / 高分子塑料」文字｜人类垃圾铁证
- `残卷石碑`｜解读｜老祖宗记录：星光线早已绝迹｜时间线铁证

**隐藏线索 ×3（可选探索，救赎结局前置）**
- `长老的旧账`｜长老居所隐秘处｜揭示长老早知真相却隐瞒｜「为何无人打破规则」
- `人类渔网商标标签`｜深海某处｜人类来源的直接铁证｜「毒药的真面目」
- `前辈人鱼的遗言刻痕`｜暗礁深处｜曾有人尝试挣脱的先例｜给予汐「打破规则」的勇气

**剧情物件**
- `尾鳍丝线`｜点击观察当前束缚状态，承载窒息感
- 珊瑚、礁石、岩壁等场景可交互物

**NPC / 角色**
- `长老`（约 220 岁）｜主持仪式、催促汐补齐丝线；尾鳍上缠着百年前的天然星光线（柔和蓝光）
- `前辈人鱼 / 莉娅姐姐`｜第一章疲惫伏笔 → 第三章受创呼应
- `族群长辈`｜世界观铺垫

## 5. 关卡与成长（五章详细）

### 第一章 · 稚海珊瑚区 · 盼长

- **固定场景**：浅海珊瑚坪（明亮纯净、像素静态场景）。
- **解谜目标**：拨开海藻、打开贝壳（按空格显露），搜集 3 样「成长饰线」+ **1 个伏笔道具**。
- **伏笔道具**：`褪色斑驳的丝线残段`——藏于海藻深处，颜色斑驳、手感硬脆，与「汐纹线永不褪色」的传说矛盾；汐只当是废弃旧线，未深想。为第三章「塑料老化」埋线。
- **关键对话**（伏笔台词）：
  > 前辈人鱼（神色疲惫）：「等你到了年纪，也会有的……不过，长大的过程……可是会有点『紧』的。」

### 第二章 · 仪式浅滩 · 初缠微缚

- **固定场景**：礁石台与人鱼古老壁画。
- **解谜目标**：物品组合 + 按顺序使用丝线。

**解谜链路（5 步）**

| 步骤 | 操作 | 道具/目标 | 结果 |
|------|------|----------|------|
| 1 | 拾取 | 珊瑚容器（贝壳碗） | 入背包 |
| 2 | 使用 | 珊瑚容器 → 海水 | 得到「盛满海水的容器」 |
| 3 | 组合 | 三根饰线 + 盛满海水的容器 | 得到「浸润的饰线」→ 线索：**丝线遇水不发光，与传说「星光遇水会发光」不符**（怀疑种子 ①） |
| 4 | 观察 | 场景壁画 | 读到口诀：「**透明=纯洁、彩色=繁茂、粗=坚韧**」 |
| 5 | 使用 | 按顺序（透明 → 彩色 → 粗）递出三根饰线 | 机关启动 → 初缠仪式剧情 |

- **关键对话**（怀疑种子 ②，由台词承载）：
  > 汐：「呜……长老，这线好像有点硬，绷得尾鳍有点麻……」
  > 长老：「傻孩子，蜕变总是伴随着不适的。线缠得越紧、越密，才代表生命力越旺盛。」

### 过场 · 时间的流动与隐痛

- 黑屏过场文字：「时光在深海无声游走。」汐身体发育，尾鳍上的「勋章」一天天沉重。
- 场景切至深海交界处，汐游动缓慢、轻声喘息：「奇怪……最近怎么越来越容易累了？」
- 目击莉娅姐姐摇摇晃晃游向暗礁区（心声提示：跟上去看看）。

### 第三章 · 深海暗礁 · 异兆疑云

- **固定场景**：暗沉的深海废墟、废弃杂物堆。
- **解谜目标**：多场景物件联动推理，联想组合得出「丝线 = 人类垃圾」真相。

**三线索（链条式联动）**

| 子场景 | 线索 | 联动方向 |
|--------|------|---------|
| 暗礁 A（莉娅处） | 线索①「受创人鱼的尾鳍」：丝线勒进肉、流血 | 触发「去废墟翻找」 |
| 暗礁 B（废墟） | 线索②「包装袋残片」：印「聚乙烯 / 高分子塑料」 | 文字指向「与石碑对比」 |
| 暗礁 C（石碑） | 线索③「残卷石碑」：老祖宗记录，星光线早已绝迹 | 集齐三件 → 触发推理节点 |

- **推理节点**（集齐三件后）：汐在暗礁中央「观察点」逐一比对 → 触发结论剧情：*「这些丝线根本不是天然星光线，是人类遗弃的海洋垃圾。」*
- **关键对话**：
  > 汐（颤抖拿起印有人类文字的包装袋）：「『聚乙烯……高分子塑料……』这些东西，根本不是深海星光凝结的汐纹线！」
  > 汐（看向石碑）：「老祖宗传下来的星光线早就没有了……这几十年，我们全族缠在尾巴上的，一直都是人类丢进海里的毒药！」

### 第四章 · 成长桎梏 · 紧缚窒息

- **固定场景**：终极祭坛。
- **剧情**：汐完全成熟，身体舒展导致塑料线极度收紧。长老前来催促补齐丝线，完成正统成年礼。玩家拥有自由抉择权。

**双分支**

- **分支 1 · 顺从宿命**（直通悲剧结局）：点击祭坛丝线补齐，完成成年仪式。
- **分支 2 · 挣脱枷锁**（解锁救赎结局，需集满 3 件隐藏线索 + 3 步操作）：
  1. 点击【锋利礁石】→ 拾取尖锐礁石碎片（解锁拆解工具）
  2. 点击【尾鳍丝线】→ 用礁石碎片轻磨外层丝线
  3. 点击【粗糙岩壁】→ 摩擦残余丝线，彻底解绑

- **关键对话**：
  > 汐（对比长老尾鳍上发蓝光的天然丝线与自己皮肉里的塑料线）：「长老……您仔细看看自己的尾巴！您的线是柔软会呼吸的！可我们缠的是什么？是硬邦邦的塑料！是撕裂皮肉的绞索！」
  > 长老：「我这线百年前缠上，何曾伤我分毫？你们觉得痛，是你们这代年轻人娇气！」
  > 汐：「因为一百年前的海洋还没有这些东西！」
  > 长老：「大家缠的都是这个，这就是规则！」

### 第五章 · 终章 · 双结局

**结局 A【宿命结局：窒息的勋章】**
- 汐放弃抵抗，任由长老缠满废线，瞳孔失去光彩，沉入黑寂海底。
- 留白文案：*「我们以为的长大，是被垃圾困住的一生。海洋的窒息，从来不是意外，而是生命顺从规则的结局。」*

**结局 B【隐藏结局：破枷重生】**
- 汐割断塑料线，鲜血散开，挣脱束缚的尾鳍迸发力量，跃向高空。
- 留白文案：*「真正的长大，不是顺从规则束缚自身，而是勇于打破强加的枷锁，守护属于自己的蔚蓝。」*

### 救赎结局达成条件（合成版）

1. **觉悟前提**：集满 3 件隐藏线索（长老旧账 / 渔网标签 / 遗言刻痕）→ 汐拥有「打破规则」的知识、铁证与勇气。
2. **行动执行**：第四章 3 步操作（锋利礁石 → 尾鳍丝线 → 粗糙岩壁）。

> 两者共同构成救赎结局：既保留「隐藏线索解锁救赎」的共识，又尊重 content.md 的「3 步操作」。

### 终局与重玩价值

- **双结局**：宿命 / 救赎，两段文案与情绪完全对立。
- **隐藏线索收集**：集满 3 件解锁救赎结局，驱动二周目探索。
- **章节回顾 / 选择**：通关后自由跳转任意章节，补线索、刷另一结局。

## 7. 视觉与美术风格

- **整体**：像素风（pixel art），深海冷色调为主，营造静谧与压抑并存的氛围。
- **色彩对比**：纯净深海（蔚蓝、通透）vs 塑料丝线（斑斓、刺眼的彩色），用视觉反差呼应主题——人造物侵入自然。
- **关键意象**：长老尾鳍上的天然星光线发出**柔和蓝光**（会呼吸），与汐身上的塑料线（硬质、无光）形成鲜明对照。
- **色调演进**：第一章明亮、充满向往 → 过场后逐渐压抑 → 终章窒息感加重，配合「越长大越窒息」的情绪曲线。
- **像素细节**：尾鳍上的丝线随章节推进由「美丽装饰」变为「勒入肌理的束缚」。

---

## 8. 扩展性与重玩价值

- **内容扩展框架**：每个道具 / 物件遵循 `[获取方式] + [用途/作用] + [剧情关联]` 三要素，可低成本新增章节、线索、道具。
- **隐藏线索体系**：以「3 件」为可扩展单位，未来可增设更多隐藏剧情分支。
- **重玩驱动**：双结局 + 3 件隐藏线索 + 图鉴 100% 收集 + 6 项成就，四重动力支撑多周目。

## 9. 开发规格（原型）

当前原型基于 **Godot 4.7.2（GL Compatibility 渲染器）** 实现，用于验证第一章核心玩法。

| 项目 | 规格 |
|------|------|
| 窗口尺寸 | 1280 × 720（canvas_items 拉伸，expand 宽高比） |
| 引擎 / 渲染 | Godot 4.7.2 · GL Compatibility |
| 移动 | WASD（CharacterBody2D，速度 220 px/s） |
| 交互 | E 对话 · F 拾取 · 空格 搜索 · 1-5 选择物品 |
| 字体 | 像素字体 `assets/fonts/pixel.ttf`，全黑（缺失回退系统 CJK 字体） |
| 碰撞 | 玩家（层 1，掩码 2）↔ 障碍物（层 2，掩码 1）双向碰撞 |
| 隐藏点检测 | 距离检测（半径 60px）代替 Area2D 物理重叠 |

**关键实现要点**
- 隐藏点（海藻 / 贝壳）为 `StaticBody2D`，兼具碰撞体与「空格解锁」容器双重身份；`open()` 后视觉变淡、取消碰撞、生成可拾取道具。
- 道具 / NPC 为 `Area2D`，仅做距离交互检测，不阻挡玩家。
- 全局状态由 autoload `Game` 管理，`main.gd` 构建 UI，`player.gd` 处理输入。
- 对话立绘为**单立绘位**：只显示当前说话者，NPC（长老）在左、汐在右；立绘尺寸 `340×460`（NPC 左 `(30,240)`、汐右 `(910,240)`），内嵌对话框并向上探出，对话文字自动避让。
- 移除背包，改为**底部 5 格物品栏**：1-5 键选格（选中高亮、未选变淡），拾取道具按序填入。
- **九宫格（ninepatch）UI**：对话框 / 物品栏 / 收集度面板 / 单格底图均用 `StyleBoxTexture` 九宫格拉伸（边框 24px，单格 8px），资产缺失回退 `StyleBoxFlat` 纯色。
- **开始界面为独立场景** `scenes/start.tscn`（入口），点击「开始」→ `change_scene_to_file` 切到 `main.tscn`（珊瑚浅滩）；按钮有 `start_button.png` 用图标、缺失回退文字「开始」。
- **场景按进度推进**：`SCENE_ORDER = coral → ritual → deep`；集齐 3 样必需饰线触发 `chapter_complete` → 屏幕中央提示文字从 scale 0.4 放大到 2.0（3 秒）→ 自动 `_load_scene` 切到下一场景。ritual / deep 目前为占位（占位 NPC + 「内容还在准备中」台词）。
- **饰线 / 隐藏点美术资源用户自行导入**：`ITEM_TEXTURES`（透明/彩色/粗/褪色 4 种饰线）与 `SPOT_TEXTURES`（海藻 ×3 + 贝壳）走 `ResourceLoader.exists()` 判空，缺失回退纯色占位；海藻三张分别对应珊瑚浅滩左侧 / 右侧 / 下方三个隐藏点，贝壳藏彩色饰线。
- **提示一次性永久消失**：`Game.hints_dismissed` 标志——完成任意一次拾取操作后，左上角操作提示与附近交互提示**全部**清空，之后不再给任何提示。
- 收集度面板在右上角（「饰线 N / 3」）。
- **海藻 / 贝壳 / NPC 的位置与大小可调**：写在 `game.gd` 的 `SCENES` 表里，`pos` = 中心点像素坐标、`size` = 像素宽高，改数字即可移动 / 缩放；默认 `size` 与物品栏格子（56px）差不多大。
- **开始按钮可调**：`start.gd` 的 `@export` 变量 `start_button_size` / `start_button_position` 控制按钮大小与位置，选中场景里的 Start 节点在 Inspector 里直接改。
- **操作提示分 5 行**：左上角提示「WASD 移动 / E 对话 / F 拾取 / 空格 搜索 / 1-5 选择物品」每条占一行。
- **行走动画容错**：`player.gd` 逐方向加载 `walk_{方向}_{0/1}.png`，缺某一帧不再导致整套动画回退（缺第 2 帧时复用第 1 帧，该方向静止）。
